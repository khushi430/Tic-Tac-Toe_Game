# Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Features

- Two-player Tic Tac Toe
- Displays the winner
- Detects draw when there is no winner
- New Game button
- Reset Game button
- Interactive user interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Play

1. Player O starts the game.
2. Players take turns selecting a box.
3. The player who gets three symbols in a row wins.
4. If all boxes are filled and nobody wins, the game is declared a draw.

## Project Structure

- `index5.html` - Game structure
- `style6.css` - Game styling
- `sixth.js` - Game logic
